GPT-6 Astra（ジーピーティーシックス・アストラ、2026年9月3日リリース）は、OpenAI（オープンエーアイ）の最上位モデル。前世代 GPT-5.6 Sol（ソル）からの一番大きな差分は、**「パソコンを人の代わりに操作する力（computer use＝コンピューター操作）」と「多段の作業を最後までやり切る力」**。チャットで答えるだけでなく、ブラウザ・専門ソフト・ターミナルを自分でクリック／入力して、フォーム入力・CRM更新・資料作成・コード修正・3D制作までを一気通貫でこなす。

このノートは「Astra で具体的に何ができるか」を、**公式ページ・公式ドキュメント・公式ページ掲載の顧客コメントだけを根拠に**、渡せる作業のかたまり（8領域）に整理したもの。動画タイトルの「100連発」はテンポの目安で、本文で挙げる事例は **公式が示す能力に紐づく「頼み方の具体化」**（OpenAI が100個を列挙したわけではない）。**動画では各領域の代表例を「今まで → Astra」の形で具体的に解説し、全96件の一覧はこのページ（下記 3〜10）に置く。**

**確度マーク**: ✅（公式ページ・公式ドキュメントで確認済み）／🔶（一次情報あり・解説メディア基準）／⚠️（未確認・推測）。料金・利用枠・仕様は変わるため、使う前に必ず公式で最新を確認すること。

## TL;DR（まず3行で）

- Astra の一番の変化は「**画面を自分で操作して、多段の作業を最後までやる**」こと。だから活用は「チャットで聞く」ではなく「**作業ごと渡す**」で考える。
- 公式が示す力は8領域（パソコン操作／資料作成／調べ物／Web・アプリ制作／コーディング／研究・分析／会社の実務／日常タスク）。**自分の仕事に当たる領域が1つあれば、今日から試せる**。
- ただし **単価は約2倍・枠は少なめ**、サイバー安全チェックで**正当な作業も止まることがある**、**曖昧な依頼だと質問で止まる**。全部を移す必要はなく、まず「毎週やっている多段の作業」を1つ渡す。

## Astra とは（仕様と、どのプランで使えるか）

OpenAI API のモデルカードは Astra を「**一番むずかしい、最初から最後まで通しの仕事のために作られた最上位モデル**」とし、向く用途を「複雑な推論・コーディング・コンピューター操作・調べ物・資料づくり」と書いている。✅

| 項目 | 値 | 確度 |
|---|---|---|
| リリース | 2026年9月3日（限定組織→数日で全 Plus/Pro/Business/Enterprise・API・Azure・AWS Bedrock） | ✅ |
| 料金（100万トークンあたり） | 入力 $10 ／ 出力 $50 ／ キャッシュ入力 $1 | ✅ |
| 扱える文章量 | 約105万トークン（最大入力 約92万・1回の出力 最大12.8万） | ✅ |
| 知識のカットオフ | 2026年4月30日 | ✅ |
| 入出力 | 入力＝テキスト＋画像／出力＝テキストのみ | ✅ |
| 使えるツール | Web検索・ファイル検索・画像生成・コード実行・シェル・MCP（エムシーピー）・**コンピューター操作**ほか | ✅ |

**どのプランで使えるか（活用の前提。ここを外すと「使えない」と誤解する）**：

| プラン | Astra が使える場所 | ひとこと |
|---|---|---|
| 無料 | 使えない | まず有料プランが必要 |
| ChatGPT Plus | 「Work」と「Codex（コーデックス）」の中だけ | 通常チャットの最上位は今も GPT-5.6 Sol |
| Pro / Business | 通常チャットでも（"GPT-6 Pro" として） | フルに使うならこちら。管理者は既定オフ |

ChatGPT の5時間あたりの利用枠は、Astra で **5〜45通が目安**（タスク・設定で変動）。✅ 単価が前世代の約2倍になったこともあり、「重い設定のまま回すと請求が跳ねる」という声がある。その対策は料金の回で別に扱う。この動画は **「何ができるか」** に絞る。

## 前世代 GPT-5.6 Sol と何が違うのか

答えは「**賢さより、代わりに動く範囲が広がった**」。同じ仕事で、自分がやる工程が減る。

たとえば「毎週の売上レポートづくり」を①データを集める→②表に整える→③グラフにする→④スライドにする→⑤社内に共有する、と分けると、Sol までは①〜⑤を全部自分で操作していた。Astra は **①〜④を代行して、⑤の直前まで持ってくる**（送信は承認を挟む）。工程そのものは同じで、"誰がやるか"だけが変わる。

数字で見た差分（すべて公式ページのベンチマーク表 ✅）：

| テスト | GPT-6 Astra | GPT-5.6 Sol | 何を測るか |
|---|---|---|---|
| Agents' Last Exam | 59.3% | 53.6% | 実ソフトでの専門作業（Claude Opus 5 は 55.5%） |
| OSWorld 2.0 | 72.6% | 65.7% | パソコン操作（Astra 約40分／Sol 約75分／タスク） |
| Terminal-Bench 4.0 | 57.9% | 37.3% | ターミナルでの複雑作業 |
| ScreenSpot-Pro | 92.7% | 76.9% | 画面上の要素を正しく指す精度 |
| Mind2Web（速度） | Sol 比 1.9倍速 | — | 同じ作業の完了スピード |

最高スコア設定では、Astra は Opus 5 より **約65%少ない出力トークン**で同等以上を出している（＝速くて、量も少ない）。✅

## 活用事例 その1：パソコン操作の代行

公式ページは Astra を「**世界最高のコンピューター操作モデル**」とし、「オンラインフォームへの入力、CRM の顧客レコードの更新、カレンダーの整理といった面倒な作業をこなす。メールや文書エディタの中で調べ物をして、要約の下書きまで作る」と明記している。✅ ここから作れる「渡せる作業」：

1. Web フォームへの入力（申込・アンケート・登録）
2. CRM（顧客管理ソフト）の顧客レコードを一括で更新する
3. カレンダーを整理して予定を組み直す
4. 複数タブを開いて商品・プランを比較する
5. メールの中で調べ物→返信の下書きまで作る
6. 文書エディタの中で要約の下書きを作る
7. 役所・病院・施設の予約を代わりに取る（確定は承認）
8. 条件に合う候補（病院・保育園など）を探して並べる
9. 画面に出た不具合を切り分けて原因をさぐる
10. ソフトを自分でインストールして動作テストする
11. 作った Web サイトの全機能を触って確認する（画面チェック）
12. Power BI（パワービーアイ）を操作してレポートを組む
13. 表計算ソフトで集計・整形・関数の当て込みをする
14. 定型書類（米国の Form 1040 のような）に記入する
15. スクリーンショットを見て操作手順を書き起こす
16. 設定画面を開いて指定どおりに変更する（変更前に確認）
17. 買い物リストを作って必要数まで整える
18. 大学・学校・講座を条件で比較して表にする
19. キャリアサイトを操作して条件に合う求人を集める
20. 回路CAD（キャド）で基板レイアウト（部品配置・配線）を下書きする
21. 複数サイトから最安値・在庫を調べてまとめる
22. ダウンロードした資料を所定フォルダに振り分ける

公式デモでは、こうした生活タスクを **「2分54秒」** で処理する様子が公開されている（編集された抜粋）。

**向かない場面**：送信・購入・予約確定など「元に戻せない操作」。承認を挟む前提で頼む。

## 頼み方のコツ

公式のモデルガイダンスに、Astra を動かすための書き方が載っている。✅

- **「やって」と言い切る**：「〜できる？」「〜したい」「手伝って」は"やってという指示"として扱う、と公式が推奨。Astra は「やりましょうか？」で止まりがちなので、最初に「最後までやり切って」と伝える。
- **先に条件、あとで清書**：結果が変わる判断だけ聞かれる前提で、対象範囲・期限・出力形式を最初に渡す。途中で方針を変えても、Astra は元の依頼と制約を保ったまま方向転換する。
- **決まり文句を禁止する**：文章がかたいときは「"delve" "leverage" "In short:" などの決まり文句を使わないで」と指定する（公式のブロックリスト）。
- **過剰なテストを止める**：小さな可逆の変更に「実装をなぞるだけのテストは不要」と添える。

そのまま貼れる例（プレゼントのテンプレより1本）：

```text
目的: 毎週の売上レポートを、社内共有の直前まで仕上げてほしい。
前提: 参照するのは共有ドライブの「売上_今週.xlsx」と先週のレポート「売上_先週.pdf」。
やること: ①今週分の数字を集計し、先週と同じ表の形にそろえる ②推移と内訳のグラフを作る ③先週のスライドの型に合わせて差し替える。
判断が要るときだけ質問して。それ以外は妥当な想定で進めて、最後に「変えた点」を3行で報告して。
出力: 完成スライドの下書き＋変更点サマリ。社内への送信はしないで、私の確認を待って。
```

## 注意点・デメリット

メリットだけの資料にしないため、まとめて置く。

- **安全チェックで作業が止まる**：Astra はサイバー能力が「Critical」判定。正当な作業でも一時停止・停止することがある（ChatGPT/Codex は再確認、API は停止）。✅
- **断る作業がある**：攻撃の概念実証コード（PoC エクスプロイト）の作成は現行版では拒否。✅
- **考えの中身が見えにくい**：「書かれた推論の追いやすさ」が前世代より低下。OpenAI も「深刻に受け止める」と明記。✅
- **知識は2026年4月末まで**：それ以降の出来事は自分で情報を渡す必要がある。✅
- **曖昧なまま渡すと質問で止まりがち**：条件を先に渡す・「やり切って」と言う。
- **単価は約2倍**：入力 $10 / 出力 $50。5時間枠は 5〜45通が目安。重い設定のまま回すと請求が跳ねる（対策は料金の回）。✅
- **公式の実演動画は編集された抜粋**：「15分で3Dアプリ」が誰でも同じとは限らない。
- **ChatGPT Plus の通常チャットは今も Sol**：Astra を使うには Work / Codex、または Pro / Business。✅
- **元に戻せない操作は承認を挟む**：送信・購入・削除は承認フロー前提で頼む。

## まとめ

GPT-6 Astra の一番の変化は「画面を自分で操作して、多段の作業を最後までやる」こと。だから活用は「チャットで聞く」ではなく「作業ごと渡す」で考える。公式が示す力は8領域あり、この動画では合計96件の「渡せる作業」を挙げた。数ではなく、自分の仕事・生活に当たる領域が1つあるかどうかが分かれ目。まずは「毎週やっている多段の作業」を1つ選んで、目的・前提・やること・「判断だけ聞いて」を書いて丸ごと渡す。ただし単価は約2倍で枠は少なめ、安全チェックで正当な作業も止まることがあり、曖昧な依頼だと質問で止まる。全部を Astra に移す必要はない。
